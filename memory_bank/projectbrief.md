# Project Brief: Разъяснитель документов

## Описание проекта
AI-powered веб-приложение для автоматического анализа и упрощения сложных документов с использованием искусственного интеллекта.

## Цели
- Помогать пользователям быстро понимать суть договоров, медицинских заключений, технических документов
- Выделять риски, обязательства и важные пункты
- Создавать краткое резюме и чек-лист действий
- Отвечать на вопросы по документу

## Рамки проекта
- **Технологии:** Next.js 14, TypeScript, Tailwind CSS, shadcn/ui, Supabase, OpenAI GPT-4
- **Форматы документов:** PDF, DOCX, TXT
- **Целевая аудитория:** Предприниматели, фрилансеры, студенты, юристы, HR специалисты

## Ключевые преимущества
- Простой и понятный интерфейс
- Полная поддержка русского языка
- Быстрая обработка документов (<30 секунд)
- Доступные цены для малого бизнеса
