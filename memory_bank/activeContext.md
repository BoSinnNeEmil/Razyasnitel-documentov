# Active Context

## Текущий фокус
**Задача:** Завершение локальной настройки окружения и проверка MVP

## Активные решения
- Использовать проектный `opencode.json` для конфигурации MCP
- Подключить удаленный Supabase MCP к проекту `oqkzutrxhvzvimvuhkbn`
- Сделать Google OAuth опциональным, чтобы локальный запуск не блокировался пустыми переменными
- Подготовить локальный `.env.local` шаблон для запуска приложения
- Использовать Biome как основной инструмент форматирования и линтинга для кода, исключая Markdown
- Валидировать проект через `bun run lint`, `bunx tsc --noEmit` и `bun run build` без управления dev-сервером

## Приоритеты
1. Настройка переменных окружения Supabase в приложении
2. Проверка локального auth-потока без обязательного Google OAuth
3. Комплексное тестирование MVP
4. Исправление критических багов
